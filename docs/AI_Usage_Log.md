# AI Usage Log

I utilized an AI assistant (Gemini) during this project for the following tasks:
* **Scaffolding:** As an aid during the decisions made about the tech stack, to decide between frameworks.
* **Testing:** Generating the baseline Vitest unit tests for the optimization engine, as well as the mock data such as test stores and items.
* **UI Implementation:** Converting a static UI design into responsive Tailwind CSS code, manual debugging was done for overlapping elements.
